# hybrid-day-brand-assets

Ficheiros públicos da marca Hybrid Day®: logótipos, ícones das caixas de email, imagens para email e para o tema do Microsoft 365. Servem para qualquer ferramenta que peça um link de imagem (assinaturas de email, Brevo, Shopify, bilheteira, tema do Microsoft 365).

Endereço público: https://hybrid-day.github.io/hybrid-day-brand-assets/

## Estrutura

- `logos/hybrid-day/`: HYBRID_DAY_LOGO_BLANCO (fundo claro), NEGRO (fundo charcoal), MONO_BRANCO e MONO_PRETO, em SVG e PNG
- `logos/iberian-league/`: badge e versões monocromáticas, em SVG e PNG
- `icons/mailbox/`: um ícone por caixa @hybrid-day.com (800 x 800 px)
- `email/`: imagens para a assinatura de email
- `tema-microsoft/`: logótipos do tema do centro de administração Microsoft 365

## Regras

Só entram ficheiros que possam ser públicos. Documentos internos, contratos e dados de pessoas nunca vêm para aqui.

Os logótipos vêm do manual de marca (novembro 2025) e não se alteram: sem recolorir, distorcer ou recriar em texto. Quando o design system e o manual de marca forem consolidados, os ficheiros são substituídos mantendo os mesmos nomes, para os links já em uso continuarem a funcionar.

HYBRID DAY® é uma marca registada da Forma Bestial, Lda. Evento organizado pela Exclamação Radical, Lda.
